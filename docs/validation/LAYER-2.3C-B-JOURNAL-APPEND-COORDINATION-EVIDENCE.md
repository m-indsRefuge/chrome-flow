# Layer 2.3C-B Journal Append Coordination Evidence

This slice migrates the active side-panel journal submit path from a direct whole-workspace write to schema `constellation-journal-append-request-v0.1`. The service worker validates the sender, constructs the runtime mutation authorization and revision, and returns `constellation-journal-append-response-v0.1` evidence.

Pure fake-adapter tests use `Promise.all` and a deterministic queued lock to prove concurrent entry and duplicate-operation serialization, one active critical section, latest rereads, and revision survival. They also cover strict request/ledger validation, intrinsic entry identity, replay and conflicts, ledger loss, write/verification failures, complete-workspace preservation, exact lock identity, client retry identity, malformed responses, and stable serializability. Committed, no-change, and replayed success all require fresh compatible verification. Persistence order is workspace peer write, compatible reread verification, then session-ledger write. A ledger-write failure after workspace commit is retry-safe because the same entry is recognized without a second revision increment.

No live Chrome, storage, IndexedDB, browser projection, network, or extension validation is performed. The session ledger may be lost on extension or browser lifecycle events. This slice proves journal-versus-journal coordination only; reconciliation and other whole-workspace writers remain an explicit Layer 2.3C-C risk. Rollback is the uncommitted working-tree diff.

The final authority correction distinguishes absent ledger keys from all present malformed values, validates the complete ledger object, validates exact response shape and identities, shares one in-flight client send, and requires canonical and legacy peers to be present and equivalent for every verified success. Ledger-write failures after verified no-change or replay use `operation_ledger_write_failed_after_verified_state`, while the after-commit reason is reserved for a write committed by that attempt.
